# Checklists & Anti-Patterns

## Format Checklist

- 第一行是否为 `# AGENTS.md`。
- 是否包含 `|IMPORTANT:`。
- 标题后非空行是否全部以 `|` 开头。
- 是否移除了 `##`/`###` 与代码围栏。

## Language Checklist

- 规则说明是否遵循目标项目主要语言（中文或英文）。
- 路径、命令、文件名、目录名、代码标识是否保持英文。
- mandatory `|IMPORTANT:` 是否保持英文原文。

## Content Checklist

- 是否覆盖项目结构、工作区、配置文件、构建/测试命令。
- 路径是否真实存在且拼写准确。
- 目录规则是否区分“官方事实”与“项目约束”，避免混写为同一强制层级。
- 是否包含提交规范或 PR 检查项（若项目需要）。

## Conciseness Checklist

- 是否将解释性文字压缩为索引事实。
- 是否避免一行承载多个不相关主题。
- 行数是否在可维护范围（建议 15-35 行）。

## Anti-Patterns

- 用传统章节散文替代索引行。
- 保留大段解释、长代码块、重复说明。
- 写入不存在路径或“猜测式”命令。
- 将项目自定义限制误写为官方硬性规则。
- 缺少 `|IMPORTANT:` 导致优先策略不明确。
- 说明与命令语言混乱（例如路径被翻译成中文）。
